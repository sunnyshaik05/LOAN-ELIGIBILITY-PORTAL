# Loan Eligibility Portal

A full-stack web application that checks whether a user is eligible for a loan based on their personal and financial details.

## 🚀 Features

- User loan application form
- Loan eligibility checking system
- Automatic approval/rejection decision
- Applicant data storage in MongoDB
- Result display with eligibility reason
- Secure backend API integration

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
